我是怎么搭建起这个博客的

2026年9月15日

今天我做了一件很酷的事：从零搭建起了自己的博客。我即将在武汉大学开启一段新的人生，看到有许多学长学姐都分享出自己的 CS 学习经历，我也想用这个博客来记录我在武汉大学国家网络安全学院的学习经历，希望对 everyone 有帮助。

Step 1 我申请了 GitHub 的学生包：在这一步中，我遇到了许多问题，比如 GitHub 英文界面看不懂，Education 申请了三次才通过，等等，但是在 AI 的帮助下，这一步顺利完成了。

Step 2 领取免费域名：GitHub 的学生包里赠送了一年的 .me 域名，也就是现在这个网站，在 AI 的指导下我学会用 GitHub 来编辑这个网站。

Step 3 建仓库开 Pages：在 GitHub 里创建一个仓库，在 Setting 里把 Pages 里的 branch 修改为 main /root，之后点击 Save 保存。

Step 4 绑定域名配 DNS：在 namecheap 网站找到 Domain List，找到对应的域名点 Manage → Advanced DNS → Host Record，具体操作问 AI，我也是照着 AI 来的。

Step 5 你现在看到的这篇文章。
